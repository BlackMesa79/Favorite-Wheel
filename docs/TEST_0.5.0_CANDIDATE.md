# 0.5.0 合并测试与验收记录

整理日期：2026-10-08。测试对象：0.4.8合并构建及0.4.9输入隔离修复；正式版统一为0.5.0。用户已确认合并项目基本正常、0.4.9测试一切正常并授权发布。下面细项为原回归计划，未逐格勾选不表示发布仍阻塞。

根据聊天中明确反馈，0.4.1全部背包/大量物品与0.4.2减速基础使用已测试正常；2026-10-08用户反馈0.4.3–0.4.8合并项目“经过测试基本都没有问题”，但新发现轮盘内RB会打开Horde。未提供逐项/逐运行时清单，因此保留下面细项供查阅，不把每项分别标为已验收。下面未勾选代表尚未确认，不代表已知仍有故障。本地逻辑/编译/布局/离屏验证通过，不替代游戏实测。

先保留现有INI，准备一份可返回的存档和对应.skse文件；直接用当前配置测试升级兼容。使用“减速20%”开始测试，再抽查暂停与正常速度。装备身份问题优先使用原反馈角色/库存；手柄翻页优先请原反馈者复测。

## 1. 时间恢复与反复开关（0.4.3）

- [ ] 减速下连续开关轮盘十余次，包括Q关闭、Esc关闭、点击药水/装备关闭：每次都及时恢复开盘前速度，不残留暂停、越来越慢或无法再打开。
- [ ] 减速/正常速度→F2设置、预设命名/管理/确认窗口：子窗口暂停；返回轮盘恢复选择的模式；关闭后正常运行。分别检查设置应用与取消。
- [ ] 轮盘打开时Alt+Tab后返回，及通过正常操作触发读档/其他阻塞菜单：轮盘取消后没有残留暂停/减速，重新打开与使用物品正常。
- [ ] 在已有慢时间效果下开关轮盘：关闭不错误取消原效果或把速度强制恢复为正常。若安装其他时间模组，至少检查日常使用的组合；外部改变时间时轮盘主动关闭可以是正常让出控制。
- [ ] 快速在多个物品之间悬停并关闭重开：详情对应当前物品，没有一直残留“物品已变化”、卡住不更新或无法再执行的现象。

任务异常恢复与并发保护已有本地故障注入测试，不要求玩家人为制造崩溃；这里用反复开关/子窗口/取消检查真实引擎流程。第三方时间控制的同值写入等仍有识别限制，不能据此宣称所有时间模组兼容。

## 2. 键鼠移动与输入恢复（0.4.4）

- [ ] 减速与正常速度：按住W移动→开盘，保持原方向；松W立即停止；轮盘中新按A/D/W/S只操作UI。W+D斜向移动分别松开，应只停止对应方向分量。
- [ ] 静止→开盘→按住W→关闭：无需重新按W即可移动；若关闭前已松W，则不能自动移动。分别用Q、Esc及点击物品关闭抽查。
- [ ] 暂停模式、进入F2/预设窗口再退出：最终关闭后仍按住的方向恢复，不需要重新按下，也没有持续自动移动。
- [ ] 若重绑过移动键，用实际绑定重复以上操作。奔跑/潜行等切换状态不承诺保留，本轮目标是方向输入。
- [ ] 轮盘操作后关闭，按住鼠标左/右键不误攻击；松开再点击攻击正常。关闭后的原生数字快捷槽仍可使用。

## 3. 手柄移动、分页与防穿透（0.4.4、0.4.7）

- [ ] 同一分类准备超过10件条目，十字键上/下反复短按，每次翻一页、首末循环；收藏页与有多页的功能列表均抽查。LB/RB仍切换类型。
- [ ] 按住默认开盘键进入轮盘不误翻页；松开后再按可翻页。长按不连续翻页属于当前设计。只有一页时上下不改变页码，也不清除选中。
- [ ] 默认配置轮盘关闭时，上打开轮盘、下仍打开原版收藏菜单；轮盘打开后上下都翻页，不唤出原版菜单。自定义入口/修饰键也抽查。
- [ ] 推动左杆移动→开盘，人物保持开盘时方向；换瞄准方向不改变人物方向；回中停止；再次推动只选择UI；关闭交回当前杆位。右杆在轮盘中不转镜头。
- [ ] A使用、X左手/预设管理、B关闭、Y切轮盘、Start设置及设置LB/RB正常。扳机/按钮保持到关闭不误攻击，松开后游戏操作恢复。
- [ ] 失焦/返回、读档、手柄断开重连后，重新按上下可翻页，不残留移动或吞键。

最需要反馈者确认的是十字键翻页。检查时说明手柄型号、Steam Input/其他重映射是否启用；不能把“同分类只有一页”视作无法翻页。

## 4. 装备预设匹配与已装备标记（0.4.5、0.4.6）

- [ ] 原Shattered Royal Armor反馈者：穿齐护甲与配件，新建/覆盖预设后立即可用；旧预设也检查。切另一套后穿回、再次点击精确整套卸下，武器与盾牌保留。
- [ ] 保存游戏后重新读档，预设仍可用；同款备用副本、已强化/附魔/改名的实际装备，保存与切换不误选另一件不同实例。
- [ ] 手动穿齐预设所有保存装备→开轮盘，应显示已装备；额外加首饰仍保留标记；少穿一件后标记消失；手动穿回后恢复。
- [ ] 精确整套再次点击全卸；如果额外穿了其他受管理衣物，虽有已装备标记，点击仍按原规则卸装后换为预设，不按“已装备标记”直接全卸。这是保留的执行语义。
- [ ] 把预设中一件装备暂存箱子后，不可用项详情应指明具体配件；恢复原件后可用。保存后再次强化/附魔/改名可能需要覆盖更新，不要求自动匹配新属性。
- [ ] 若保存前校验失败，应明确提示且不覆盖已有预设。导入/导出和预设中文命名各抽查一次，Skyrim Text Bridge候选选择/确认与光标正常。

0.4.5修复了可复现的等价副本误判，但尚未证明它就是原Shattered反馈的全部原因。需要原反馈者结果才能确认该具体兼容问题。没有唯一ID的完整签名相同副本允许互换；不同UID、强化、附魔、名称仍严格匹配，不能仅因外观相同要求标记。
