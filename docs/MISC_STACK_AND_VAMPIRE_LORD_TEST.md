# 杂物显示堆叠与吸血鬼领主边界测试版

## 2026-10-25 撤回音效试验

用户确认修复吸血鬼领主 T-pose 后，还原形态也恢复正常，并要求停止音效修复、恢复至开始处理音效前的状态。已撤回所有领主补播音效、额外装备/能力键诊断、临时解除暂停装备策略及对应新增测试；保留已验证的杂物合并和领主功能边界。先前音效试验记录和修改前文件保存在 build/backups/rollback-before-vampire-audio-*，不再作为当前实现说明。未修改其他模组、动画生成结果或用户配置。

日期：2026-10-24。基于当前 0.8.0 工作区；保留已有战斗循环中心显示等改动。

## 实施

- 非可用 MISC 物品按 base form、显示名、收藏状态、原始快捷键标记与所有权归并显示。允许数量与 UniqueID 不同；有改名或其他未明确支持的额外数据时保留独立行。仅合并轮盘目录，不改游戏库存、不删除 ExtraDataList，也不改变存档。不同 FormID 的同名物品不会合并。
- 数量使用已分配的库存数量预算，再以 64 位累加并限制到 int 上限。原本单行的矿石仍是单行。武器/护甲/消耗品不进入这个新增归并分支。
- 多实例杂物行保留一个真实实例作为详情锚点；它是只读显示集合，不支持在轮盘中改绑快捷键，以免只改到部分成员。尝试改绑会显示现有“不支持”提示。不同原始快捷键的成员从一开始就分开显示。普通杂物没有新增装备/使用能力。
- 吸血鬼领主通过 Default Object Manager 的 `kVampireRace` 识别；允许技能来自 `kVampireSpells`，要求玩家实际拥有且为可装备的主动法术/能力。不会复用人形收藏技能或把人形背包显示出来。不依赖 Dawnguard 加载序号，也不因普通人形吸血鬼不可玩 race 标志而限制其功能。
- 狼人与其他未识别兽化仍交回原版。缺少吸血鬼技能列表时也交回原版。自定义种族模组需正确提供默认种族/技能列表才会被本路径识别。
- 吸血鬼领主的收藏/功能入口均打开技能轮盘，禁用功能轮盘切换、设置入口、快捷槽改绑、战斗预设快捷键和循环快捷键。装备技能时使用该技能定义的装备槽，不进行人形双持清空/左右手转移。
- 开盘期间形态改变会取消当前轮盘；排队动作记录原形态，并在提交前再次检查形态和动作白名单。已经开始的换装/战斗作业在兽化后中止，防止继续执行后续步骤。不尝试撤销变身前已完成的装备动作。
- 提示区使用专属中英文技能模式说明，隐藏不可用功能和改绑提示；其他语言回退内置英文。开盘日志新增 `formMode`：0 人形、1 吸血鬼领主、2 未支持兽化。

## 验证

DLL 编译通过。InventoryTests、WheelLogicTests、RuntimeLayoutTests、ActorRuntimeTests、CombatPresetTests、CombatCycleTests 六项通过。新增覆盖三类乐器各 30 个独立标识实例、数量守恒、所有权/快捷键/名字/未知数据隔离、单行矿石、溢出边界与形态动作策略。

实际 DrawWheel 通过 WARP 在 1280×800 离屏渲染。检查压缩预览 `build/compat-vampire-zh.jpg`：中文技能模式提示完整，没有普通轮盘切换、设置或改绑提示。此预览使用合成技能数据，不代表游戏内吸血鬼技能来源或使用行为已验证。

没有修改渲染接入，不声称修复 PureDark/TRP 不可见问题。没有游戏内复现变身闪退，也不能将新增边界称为已修复所有闪退。

## 游戏内复测

1. Favorite Things + 鼓/笛/鲁特琴：比较每类总数量、格数；不同所有权、名字或特殊数据应按上述边界保留。矿石、武器改名/附魔/强化堆叠回归检查。
2. 正常人形与人形吸血鬼：收藏、功能、战斗预设、循环组与快捷键仍可用。
3. 吸血鬼领主：检查技能列表与原版可用技能相符；已获得和未获得技能正确区分。两种入口均不显示人形装备/预设；鼠标与手柄选择均使用技能原定槽。
4. 尝试切换功能轮盘、F2、数字改绑、战斗/循环快捷键，确认不会触发轮盘的人形功能。原版其他模组自己的快捷键不由本补丁接管。
5. Live/Slow 模式开盘中变身/还原，以及提交装备后立刻变身：轮盘关闭，排队或进行中的后续人形动作取消。还原后重新开盘恢复正常功能。
6. 狼人仍使用原版。若领主未开盘或技能为空，收集 Favorites key 的 blocked 原因、formMode 和目录日志；勿直接去掉控制组或菜单安全门槛。

测试包不带主 FavoriteWheel.ini，不自动安装到真实 MO2 目录；原正式发布包保持不变。
