# 0.5.0 正式发布记录

日期：2026-10-08。公开名称：Favorite Wheel - Radial Actions。

本版合并正式版0.4.0之后的0.4.1–0.4.9改动。用户已确认全部背包与减速基础功能正常、后续合并项目基本正常，最后确认0.4.9的Horde/RB隔离修复测试一切正常，并授权发布0.5.0。本轮统一版本、整理发布材料、编译部署与打包；不增加新游戏功能或修改已验收的输入、装备、时间与绘制逻辑。

## 合并改动

| 开发版本 | 合并内容 |
| --- | --- |
| 0.4.1 | 可选全部背包，默认只收藏；轻量目录、十项分页、按需悬停详情，直接开功能轮盘避免库存采集 |
| 0.4.2 | 暂停/减速/正常速度；相对减速5–100%，默认20%；设置/预设窗口临时暂停；游戏行为标签；动态库存刷新 |
| 0.4.3 | 时间与轮盘生命周期同步、排队任务异常恢复、旧任务隔离、悬停详情缓存与提示修复 |
| 0.4.4 | 保留开盘前方向到松键，轮盘新方向只操作UI，闭盘held立即恢复；左杆方向锁定与回中停止 |
| 0.4.5 | 完整签名相同且无UID的装备副本匹配、保存前校验、具体缺失配件和身份诊断 |
| 0.4.6 | 手动穿齐预设也显示已装备，额外衣物不抑制标记；实际换装/精确整套卸装语义保持 |
| 0.4.7 | 手柄十字键物理边沿翻页与零时长松键恢复；开盘长按不误翻页，单页保持选择 |
| 0.4.8 | 法术/龙吼/能力八大类，主动类型过滤，三个翻译键与英文回退 |
| 0.4.9 | 捕获按钮从下游派发链移除，避免RB误触发Horde/声音槽能力；保留必要Release、移动与IME |

全部背包模式的法术、龙吼、能力仍只列收藏；原生1–8槽位分配仍要求收藏。预设仍排除武器、盾牌和弹药。保存数据格式和旧配置不迁移、不重置；升级保留INI、语言/主题文件及对应.skse存档。
