# 数值排序与旧提示迁移

武器增加伤害降序／升序、重量升序、价值降序；装备增加护甲值降序／升序、重量升序、价值降序；普通法术增加法力消耗降序／升序。按 T 循环，Shift+T 编辑；其余分类不出现无意义的数值模式。旧模式编号保持不变，追加 7–10，存档包含新模式时旧版本无法读取排序记录。

数值来源与详情面板一致：武器 GetDamage、护甲 GetArmorValue、法力 CalculateMagickaCost、实例重量和价值。箭矢使用基础伤害；法杖没有物理伤害值。持续施法按每秒消耗，与单次施法消耗直接比较数值，不声称比较相同时间的总消耗。法术没有混合效果“总伤害”排序。价值不等于商店成交价。排序使用原始精度，而面板可能四舍五入。

切换到数值模式通过游戏线程重新收集目录，期间阻止条目操作以免误选；只采集已启用数值排序的分类，不收集效果描述。默认、名称、类型和自定义模式保持轻量目录。当前已有的目录刷新／重新打开会重算数值，不新增持续轮询；属性暂时变化而目录尚未刷新时，排序可能滞后于详情。大背包启用数值模式仍需游戏内验证耗时。无效、缺失或非有限值统一排尾，零有效，同值按名称再稳定排序。

提示滞后根因是 after_build 仅追加缺失语言键。scripts/language_migrations.lua 现在精确匹配曾发布的 F3/F4、按钮版、工具小轮盘版默认提示，并替换为当前源码值；未知／自定义提示不覆盖。首次迁移前将语言文件备份为 *.before-controls-migration，后续迁移幂等，保留其他文字和换行，不覆盖主 INI。
