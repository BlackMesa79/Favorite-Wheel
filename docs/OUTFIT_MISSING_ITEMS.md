# 装备预设：跳过缺失物品

更新：2026-11-15。0.11.0 候选构建已实现功能与编辑页布局整理；用户当前不便实机测试，TNG／灯笼兼容性待反馈者单独验收。

## 使用方法

在功能轮盘右键管理目标装备预设，打开“编辑预设”，将底部“跳过缺失物品”设为“开”，再保存。可以点击开关、按键盘 M，或按手柄 X；保存仍使用按钮、F5 或手柄 Y。取消编辑不保存开关。

选项对每套预设独立生效，默认关闭。编辑保存后还需保存游戏，才能将设置写入该存档的 SKSE co-save。覆盖当前穿搭时保留原预设的开关；导出、导入也保留该设置。

## 行为

- 关闭：继续使用原来的严格检查，任何必需条目缺失都阻止整套预设。
- 开启：只跳过背包中完全不存在该基础物品的条目，装备其余可用部分。全部条目缺失时不执行换装，不会因此卸掉现有装备。
- 物品还在，但实例属性改变、存在歧义或重复目标时，仍按原有匹配规则处理；本选项不启用宽松匹配，也不绕过任务装备和盾牌冲突保护。
- 本次换装固定使用开始时可用的目标。被脚本重新添加的辅助物品不会自动成为本次的新目标，也不会仅因多出这些物品而判为失败。
- 换装过程中已计划的物品完全消失时跳过该步骤；仍需确认其余可用目标实际穿上，才清理计划中的旧装备。引擎调用超时或非缺失的实例变化仍会停止操作。
- 再次使用时重新扫描背包，之前缺失的条目如果已恢复，会重新纳入目标。预设里的条目不会被永久删除，不生成或复制物品，不特判槽位 52 或某个模组。
- 兼容模式中，可用目标都已穿戴时，再次点击会卸下这些目标，保留不属于这些目标的额外装备。应用预设仍会按原替换计划清理开始时穿着的其他旧装备。

存储升级为 FWO 3／co-save 记录版本 3。读取 FWO 1、2 时该选项默认关闭；旧版插件不识别新版记录，请勿用旧版插件继续保存含新版预设的存档。
