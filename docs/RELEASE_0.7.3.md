# 0.7.3 发布记录

日期：2026-10-18。受影响用户确认独立 LB+Y 手柄兼容补丁修复了问题，授权合入正式版。0.7.2、独立补丁和战斗循环测试包保留。

## 发布内容

修复部分自定义手柄映射下 LB+Y 打开原版收藏菜单、键盘仍正常的情况。组合键处理会在 Y 按下时临时送出 LB 释放事件，原实现因此认为缺少 LB。现在保留事件跟踪，同时用游戏当前原生手柄包补足入口需要的修饰键；必须确认同一主键也在当前包中，才补足对应修饰键。不添加松开宽限期，不取消原生映射的 LB 要求，保留单按 Y 的原有动作。

沿用阻塞菜单、控制组和输入所有权规则；额外 Actions 修饰键保持其优先级。非原生设备保留事件路径。入口日志包含 `engineAvailable`、`engineMask`、`openingMask` 和 `event`，便于后续诊断。

本版从已被反馈者验证的独立补丁源码构建，运行时代码仅更新版本元数据及启动日志。正式包不包含战斗循环开发功能；轮盘渲染器保持不变。不能据此把所有手柄模组组合或帧生成兼容问题视作已验证。

## 验证和交付

Release 构建后运行 18 个测试套件，包括 0.7.3 导出元数据、七个支持版本的真实 Address Library、当前／上一手柄包布局、日志中的 LB/Y 事件序列，以及真实释放后保留主键行为的检查。受影响用户已确认测试补丁解决问题；正式构建仅变更版本和发布材料。

- `dist/FavoriteWheel-0.7.3.zip`：完整安装包，不带主 INI。
- `dist/FavoriteWheel-0.7.3-source.zip`：与正式 DLL 对应的稳定源码，附逐文件 SHA256。
- `release-materials/0.7.3`：简短中英文 changelog、详情页、预览和验证记录。

升级时停用独立 controller-chord 测试补丁，以免旧 DLL 覆盖正式版本。本地正在使用的战斗循环测试安装保留，主 INI、自定义资源及既有发布包均不修改。

本次只制作本地正式发布文件，未执行 Nexus 上传、Git 提交／推送或远程 Release 创建。
