# 0.11.0 发布记录

日期：2026-11-17。用户确认 I4 图标适配和轮盘配置菜单调整已验收，授权提交、推送及正式发布 0.11.0。

## 更新内容

- 接入 I4 图标规则、SWF 栅格化与磁盘缓存，支持 Theme／I4／Original 配色和图标范围设置；主题图标包可以覆盖 I4 图标。
- 修复没有独立 I4 颜色的图标在扇区和详情中颜色不同。2026-11-15 用户重启游戏后已验收通过。
- 增加每套装备预设独立的“跳过缺失物品”选项，默认关闭。用于 TNG 等脚本动态增删辅助装备的场景；实现和离线测试完成，TNG／灯笼实际兼容性由反馈者单独测试，不能写成已验收。
- 优化预设编辑页：五行列表调整高度与行距，开关位于内容区分隔线上方，说明文字和装饰分隔线下移并保留间距，保存／取消位于底部操作区。同步点击行距，避免视觉位置与操作位置不一致。
- 设置页改为外观、图标、键盘、手柄、游戏行为五页；I4 三项移至独立图标页，外观页恢复 11 项与较宽松行距。鼠标命中和手柄 LB／RB 切页顺序同步，八种语言新增页签名称。
- 保留已验收的 SGT／MISC 乐器原生装备路径修复。

## 升级与验证边界

保留用户主 INI、自定义主题和资源。旧版预设 FWO 1／2 可读取，新增选项默认关闭；新版预设写为 FWO 3／co-save 3，详见 [装备缺失兼容说明](OUTFIT_MISSING_ITEMS.md)。需要重启游戏加载 DLL。

UI 通过真实 WARP 离屏渲染验证，覆盖全部设置页、中英文及德法文长标签、编辑页、720p 与 1440p。未接管键鼠，没有把离屏检查当作游戏内操作验收。构建、测试、哈希与具体预览路径见 `build/ui-011/REPORT.md`。

英文回复草稿：`release-materials/0.11.0/tng-reply-en.txt`。只写本地文件，未向反馈者发送。
