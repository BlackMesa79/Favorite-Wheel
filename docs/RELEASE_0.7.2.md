# 0.7.2 发布记录

日期：2026-10-16。用户确认武器堆叠与双持测试版、第二版光标修复均通过本地游戏测试，并授权制作新正式版本。0.7.1 及既有测试包保留。

## 发布内容

- 普通同款武器使用一致的数量分配、逻辑分组和手位模型；仅收藏一把时，也能选择另一把空闲副本进行双持，避免向另一手重复提交已经穿戴的实例。
- 装备过程中原生拆堆或合堆后，可以重新查找同一普通武器组，避免数量由 ×2 变成 ×1 后误走移手路径，以及卸装后误报“物品变化”。不同附魔、强化、名称、所有权、充能、毒药、唯一 ID 和未知实例数据保持分离，独立绑定的快捷键保留身份保护。
- 列表刷新按普通武器组的逻辑身份保持光标，修复钢制剑首次装备、收藏实例地址变化时的误复位。选中项真正消失、被其他物品或不同实例替换时仍会归中。快捷键变更同步更新已打开轮盘的组标识。

## 验证

用户已确认两版测试在本地通过。发布前重新构建 Release DLL 和受影响测试，运行 18 项测试套件。RuntimeLayout 校验 0.7.2 导出元数据、七个支持版本及七份真实 Address Library。HandEquip/Inventory 覆盖空闲副本选择、拆堆后的收藏标记迁移、数量守恒、不同实例/绑定排除、快捷键快照和光标选中项身份。

详细调查和测试边界见 WEAPON_STACK_HANDS_0.7.1_TEST.md。Gamepad++ 手柄打开原版收藏菜单的问题仍等待其实际按法、当前 ControlMap 和日志，未加入任何未经确认的修复；闭源帧生成器/TRP 兼容情况也未列为已修复。
