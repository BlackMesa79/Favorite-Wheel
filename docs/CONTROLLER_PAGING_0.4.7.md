# 0.4.7 手柄十字键翻页

用户确认问题为轮盘内十字键上/下无法切换同分类物品页，非LB/RB分类切换。没有该用户的事件日志，本机日志只有键鼠输入，具体手柄/输入插件组合尚未复现。

## 检查与修正

SKSE转换266/267对应十字键上/下正确；原入口分支已有`(!pad || !current.open)`保护，因此不能直接认定入口吞掉翻页。原UI只在ButtonEvent::IsDown（value>0且heldDuration==0）执行；InputGate只在IsUp（value==0且heldDuration>0）清除吞键。第一按下时长非零会跳过翻页，零时长松开会留下swallowed，阻塞下一次按下。两种事件条件可用合成输入序列复现，但尚不能认定就是用户现场。

ControllerPageButtons独立追踪266/267的物理按下边沿，每次实际按下仅翻一次，不依赖heldDuration等于零，也不会因连续零时长held重复翻页。轮盘外也观察入口键，按住开盘键进入轮盘不会立即翻页。原生入口是否打开仍依照原IsDown/修饰键/游戏状态规则；只有轮盘已打开时的十字键UI down使用边沿。手柄value为零按物理松开清除InputGate吞键，不再要求释放时长非零；原攻击/入口/其他按钮仍在实际松开前防穿透，不注入游戏事件。键盘/鼠标与移动策略保持。

失焦、读档/游戏状态重置、手柄禁用时重置边沿追踪，重置后held不能成为新翻页，看到松开或新原生down才重新启用。无长按自动连翻。单页/空分类翻页不复位光标；多页仍循环翻页并清除选中以避免误用新物品。默认轮盘外D-Pad Down原版收藏入口保持透传；轮盘内上下仅用于翻页，设置/命名窗口仍优先处理并吞键。

`Controller page input`按实际按下边沿输出raw/规范化key/nativeDown/swallowed/settings/dialog；`Controller page`记录收藏/功能、分类/section、物品数量、总页数和1起始的前后页码。一次物理按下只记录一次，没有逐帧held日志；可以区分事件未到达、输入被门控、设置窗口拦截和分类实际上只有一页。
