## 用户复测与证据

用户复测 v2 后仍是“轮盘暂停但界面不可见”。本地日志 13:16 明确包含 `route=menu-framebuffer-v2`，证明运行了 v2。开盘时实际目标和入口目标均为 format=24，收起时均切到 format=28；有非零顶点和正常动画统计，没有初始化失败。显式请求引擎 UI RTV 并未解决症状。

这排除了“仅修正当前绑定 RTV 就足以解决”的假设，不能继续凭纹理格式宣布根因。菜单回调方案在该本地环境中没有通过实测；绘制到底在什么后续阶段丢失仍未验证。前两轮 WARP 测试只覆盖独立 D3D11 模型，没有覆盖实际游戏、菜单标志、渲染线程和第三方合成顺序，不能作为可见性验证。
