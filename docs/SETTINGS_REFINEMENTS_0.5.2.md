# 0.5.2 设置细节修正

2026-10-10：用户确认左杆移动/右杆选择实机正常，提出待应用开关不能改变操作、默认轮盘移右、空分类可选。本轮仍为0.5.2开发测试版，最近正式版0.5.1，没有生成发布包。

## 行为

- 手柄页“左摇杆控制移动”仅成功应用后切换选杆；待应用开关、默认值预览、取消和保存失败保持已应用方案。选项显示待保存值，操作帮助显示实际选择杆。离开设置时清除积分缓存，避免沿用之前杆向量。
- 外观默认位置X72/Y46；新安装、缺失位置键及恢复默认值使用右侧布局。已有明确位置保留，本机安装INI为X70，未覆盖。右侧空间不足时既有详情卡自动放到轮盘左边。
- 游戏行为新增“隐藏空分类”，General/HideEmptyCategories默认1。关闭后导航/标题恢复全部八类，包括无条目的类型；重新开启回到当前目录中有物品的类型。收藏/全背包共用已有分类掩码，不增加扫描；应用退出设置时用现有目录刷新可见页。功能轮盘预设/面光可见规则保持独立。
