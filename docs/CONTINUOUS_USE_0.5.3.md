# 连续装备与手柄操作（0.5.3测试版）

2026-10-09：用户确认上一测试版总体正常，提出连续装备、扳机装备以及按键分组，并补充消耗品应仍关闭轮盘。0.5.3实现以下行为，游戏内新行为待复测。

## 行为与配置

- 游戏行为页“装备后保持轮盘打开”（General / KeepOpen），当前开发版默认1，显式保存的0仍自动关闭。
- 开启后，普通武器、护甲、弹药、卷轴/火把装备以及法术、能力、龙吼保留轮盘；面光命令同样保留。装备预设关闭轮盘以显示换装过程。轮盘中的卷轴操作是装备，真正消耗在之后施法时发生。火把无论使用哪侧按键都装在左手，再选已装备实例可卸下。
- 药水和食物，无论左右使用或手柄方案，始终按原路径关闭后调用EquipObject。毒药使用独立分类，同样闭盘，再由原版 UsePoisonFromInventory 检查武器、确认涂毒与消耗；左右按键不指定涂毒手。
- 手柄页“类型切换按键”（Controls / GamepadCategoryButtons）：0为LB/RB类别、LT/RT左/右装备；1为LT/RT类别、LB/RB左/右装备。右侧键也执行药水、龙吼、功能命令等中性动作。
- A/X仍分别使用与左手/预设管理；B返回/关闭；Y切轮盘；Start设置；十字键上/下翻同类别物品页，左/右仍切类别。新设置不改变入口键/修饰符。
- 设置页顺序：外观、键盘、手柄、游戏行为。设置中的LB/RB始终切设置页，A选择、X重置、B取消。键盘绑定行保留原捕获与重置逻辑。
- 英文内置回退及en/zh_CN翻译增加10个键，不覆盖旧翻译内容，缺键回退英语。

## 执行与审查边界

保留轮盘不是隐藏后重新打开：当前分类、页和光标、动画会话与输入隔离保持。接受新动作前检查pending/retained/outfit busy，禁止覆盖前一次命令。任务继续使用既有执行器：收藏/预设在SKSE任务、面光在玩家Update。暂停模式下普通收藏装备只允许穿过轮盘自己的单一暂停，其他动作继续等待解除暂停；不写全局pauseCount或强制解除其他菜单。

2026-10-11修正：普通收藏装备在Pause+KeepOpen时保留暂停守卫，原生物品以queueEquip=false、applyNow=true执行；法术/龙吼沿用原生装备接口。允许执行前确认守卫实际打开且PausesGame标记存在、UI暂停计数恰为1，完成后直接刷新目录，不等待冻结的PlayerUpdate。面光仍保留原先至少150ms与两次后续玩家Update窗口；预设与消耗品仍闭盘。Slow/Normal保留原速率与时间所有权检测。设置/预设管理在执行期间暂不进入。

原生动作重新解析物品身份，不保存ExtraData指针用于后续直接解引用。读档epoch、session serial、焦点、死亡、阻塞菜单、超时仍使待执行命令失效；手动关闭后已经接受的动作允许完成，但不会重开轮盘。关闭/强制隐藏/失败清理retained标记、时间会话与暂停请求。面光命令后在其接受的Update线程重新Capture，取得新revision以供下一次点击。

完成动作后合并一次轻目录刷新，不读取全库存详情。装备事件/容器事件沿用250ms合并刷新，暂停且KeepOpen时也能更新。保持原光标；悬停实例消失则清空选择，避免误用被顶上来的不同物品。LT/RT按真实按压边沿触发，持有不连发，观察轮盘外输入及设备/焦点/读档重置。原InputGate与派发链仍吞完整扳机/肩键周期，闭盘后持有或松键不会产生攻击/声音能力。

150ms窗口仅保留于需玩家更新的面光命令和Slow/Normal结算；普通装备不再主动恢复世界。第三方装备脚本与动画仍可能等到关闭轮盘后推进，消耗品保留闭盘路径。开发端未运行游戏，本地纯策略/布局/离屏验证不能替代真实动作与动画测试。此次修正与验证见[TORCH_PAUSE_POISON_0.5.3.md](TORCH_PAUSE_POISON_0.5.3.md)。

## 游戏内复测

1. 旧配置、默认关闭开关：所有使用仍自动关盘，键盘/手柄入口修饰符不变。
2. 开启KeepOpen：同一次打开先RT装备右剑，松开后LT装备左剑；两把都装备，轮盘不关，标记更新。重新选择对应已装备武器卸下，护甲/盾/法术/能力/龙吼同样检查。B/Esc正常关闭。
3. 药水与食物：RT/A或LT/X仍关闭，喝药/吃喝动画正常，不出现双消费。选择最后一件后重开数量正确。
4. 手柄方案两种逐一检查：对应类型键只切类型、另一组只装备；提示同步；十字键上下在>10物品类别继续翻页，设置LB/RB遍历四页。
5. Pause/Slow/Normal分别连续装备与切预设；普通装备保留轮盘并更新标记，预设闭盘后换装。Pause+KeepOpen连续装备不得短暂恢复世界；Slow/Normal保持所选速度。
6. 预设管理/名称/设置仍暂停，执行中的点击不覆盖动作。面光开/关连续两次均有效（新revision），随从子页状态正确。
7. 持RT/LT/RB关闭后，保持/松开不攻击或激活Horde；新的游戏内按键正常。开盘前移动保留、轮盘中新按移动只操作UI、关盘恢复既有策略。
8. 大库存连续选择不逐帧全量扫描；物品移除/外部换装刷新后不错误替换当前悬停对象。焦点切换、死亡、载入、外部菜单打开无卡暂停或重复动作。
