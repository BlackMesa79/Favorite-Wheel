Q → F2 → 游戏行为 → 时间行为 → 减速 → 应用。默认仍为暂停；减速比例默认50%，范围50–100%，每次调整5%。收藏与功能轮盘共用选择，正常速度模式不修改游戏时间。全部背包开关也移至游戏行为页，原有配置值保留。手柄设置页LB/RB循环三个标签。

INI `[General] TimeMode=0` 为暂停，1为减速，2为正常速度；`SlowTimePercent=50`。旧INI缺键默认暂停。修改设置期间游戏始终暂停，Apply保存并立即应用到普通轮盘，Cancel恢复保存值。命名、管理、覆盖/删除确认等预设窗口也始终暂停。减速/正常速度下世界继续运行，玩家仍可能受伤或死亡。

## 菜单与动作生命周期

`FavoriteWheelMenu`保持固定非暂停标志，菜单上下文及原输入门控继续捕获键盘、鼠标、两个摇杆与手柄。独立`FavoriteWheelPauseMenu`具有固定`kPausesGame`，仅在暂停模式/设置/预设窗口需要时通过UIMessageQueue开关。引擎负责平衡菜单暂停计数；不修改已在栈上的菜单标志、不手动增减UI/BSTimer的pauseCount。

正常关闭、取消、失焦、玩家失效/死亡、其他阻塞菜单、主菜单、读档、强制隐藏及渲染失败均通过Cancel/主菜单消息释放时间会话。时间检查入口有input dispatch、轮盘AdvanceMovie以及已有PlayerUpdate；不会依赖暂停中的PlayerUpdate单一入口。新MenuObserver对其他暂停/modal/application菜单的打开及时关闭轮盘，自己的两个菜单除外。

Cancel立即释放减速并请求隐藏暂停守卫及轮盘。待两个菜单均退出栈、游戏恢复且没有有效减速会话，原动作执行队列才执行药水/装备/换装/面光操作。折扇收拢按steady_clock继续绘制，不延迟恢复和动作。面光仍只在认可的PlayerUpdate线程提交开盘前锁定的请求，stale请求不自动重放，不改变目标。

## 时间会话与外部控制

使用CommonLib的BSTimer单例/当前倍率/目标倍率与原生SetGlobalTimeMultiplier。会话保存当前/目标基准，再将两者乘以比例；应用前先检查当前/目标中较低的一端，限制相对系数，使两者都不低于正常速度的50%。例如基准0.75、所选50%时，实际系数提高到约0.667，得到0.5；基准任一端已不高于0.5时不再减速、不取得会话所有权，也不把外部速度加快。旧INI低于50%的值只在内存中归一，明确Apply才保存有效值。setter后显式设置已声明的当前/目标全局值，使开闭即时生效并保持两个值的区别；不改变bChangeTimeMultSlowly、timer暂停计数、Havok参数或游戏存档时间设置。

`TimeLease`观察目标与当前进度。允许当前值朝已施加目标单调变化；结束时恢复原目标，并按比例撤销自己对当前值的缩放，保留已有渐变进度。重复释放无操作，不把速度硬写为1.0。进入临时暂停窗口先释放本轮减速，离开后重新取得最新基准；100%不取得时间所有权、不写原生倍率。

若检测到目标改变或当前值偏离允许的原生渐变区间，放弃所有权并关闭轮盘，保留外部值；不会每帧重写或把未知外部值除以自己的系数。相同值写入、区间内恰巧一致的外部变化、直接修改另一种时间效果仍无法可靠识别，没有跨插件时间仲裁协议，因此不承诺所有慢时间/击杀镜头组合都兼容。

## 实时库存与性能

TESEquipEvent/TESContainerChangedEvent仅增加玩家库存dirty stamp；减速/正常速度物品页按真实时间最短250ms合并刷新，只有dirty才扫描。设置/预设窗口和功能页不扫描。仍保持轻量目录与最多10项的页快照；不每帧遍历全部库存。刷新替换目录revision，使旧详情任务失效。新页相同扇区若换为另一身份/从空项变为物品，清空选择，避免误用；不隐式改变当前分类。

非暂停模式当前悬停详情至多每500ms重读一次以更新实时属性；稳定悬停80ms门槛及最多一个排队详情任务保持。使用前始终重新核对具体实例，失效特殊装备不回退到同Form其他实例。仅影响属性/名字而未发上述事件的外部直接数据修改可能在下一开盘才更新目录；执行核对仍会拒绝不匹配实例。
