## 使用

打开轮盘 → F2 / 手柄Start → 外观 → 外观主题 → Skyrim → 应用。

新资源为 `SKSE/Plugins/FavoriteWheel/Themes/skyrim.ini`，新增 `Style=skyrim`。语言、位置、尺寸、时间模式、输入和存档设置与皮肤独立。选择主题可即时预览，取消恢复原主题，应用后按现有主INI规则保存。默认主题依旧Classic Gold，安装/部署不修改玩家选择。

## 覆盖范围

- 轮盘扇区：不透明炭黑底、完整细线轮廓、灰色悬停和白色选中边线、内指向标记，移除原风格的金属渐变和外环刻度。
- 中心环：双细线与原创几何分隔装饰，保留中心图标、名称和状态。
- 导航：切角按键提示、小菱形与连接线分页、当前页两侧尖角；保留分类标题及其左右键提示。
- 详情卡、设置与预设窗口：切角双线框、角部线条、平面暗底；按钮使用上下细线和选中尖角，输入框改为切角轮廓。
- 快捷槽、帮助条、设置标签页、恢复默认/取消/应用及确认窗口使用同套样式。
- 保留North Etch原创线稿图标和现有字体加载/多语言回退。没有提取原版SWF、图标、纹理或字体；第二层使用项目自生成的材质，仍是受Skyrim黑白菜单启发的独立绘制风格，并非原版菜单的像素复刻。

## 主题接口与兼容

`Theme`增加 `ThemeStyle`（Etched、Skyrim），外置INI使用 `Style=etched` 或 `Style=skyrim`，允许大小写及首尾空格。缺失、空白或未知值回退Etched，Classic/Frost/Engraved/Quiet Slate无需补键。绘制风格与颜色/字号参数独立，第三方可以复制skyrim.ini创建同造型的其他配色。

Skyrim风格固定切角/平面造型，因此CornerRadius和Relief不作用于其主要面板/扇区；BorderWidth、Ornament、TextShadow、IconScale、TitleScale、LabelScale、HoverDuration、PageDuration及颜色仍有效。Ornament=0隐藏几何装饰，保留功能性边线和选择标记。

第一层不提供图片纹理、图标资源替换、自定义布局或脚本；第二层增加了可选PNG材质与Nordic边框，完整约束见[SKIN_MATERIALS_0.5.3.md](SKIN_MATERIALS_0.5.3.md)。风格不改变十格轮盘的半径、分类/分页坐标、窗口大小、按钮命中区、输入路径或开闭时长，避免主题导致交互偏差。沿用当前逐扇区展开/收起和淡入淡出。

## 性能与资源

第一层造型由ImDrawList几何生成；第二层只在渲染器初始化时加载一次可选PNG，并复用现有D3D11路径，不创建额外场景渲染目标、不采样场景、不加模糊、不改Present参数或帧率。没有新引擎地址、后台线程或每帧文件读取。保留全屏遮罩主设置，面板/扇区稳定状态不透明。

几何数量与真实GPU开销分开记录；WARP预览用于布局、字体、透明度和有限坐标验证，不能据此认定所有显卡的实机性能。原位配置保存仍沿用已审核实现，不引入启动配置写入。

## 验证

SettingsTests覆盖五主题加载、四旧主题风格不变、未知Style回退、Style大小写/空白与独立颜色参数，以及现有语言/保存/失败/撤销规则。WheelPreview可用最后一个可选参数指定1–30个模拟帧，检查悬停到稳定状态；不睡眠、不改变游戏状态。

离屏检查应覆盖8语言的设置页、收藏详情、功能/面光、预设命名/管理/确认、空分类和分页、多分辨率/尺寸及开闭动画中间姿态；包含旧四主题回归。现有预览检查字体字形覆盖和atlas复用、背景仅按设置变暗、稳定扇区不透底、坐标有限及轮盘边界。

实机建议：选择Skyrim后应用，检查收藏/预设/面光、设置四标签及预设命名；切回原主题并取消预览，检查重启保留选择；720p/1440p下查看长物品名称、说明、快捷槽和手柄提示；减速移动/连续装备/用药与原有逻辑一致。此次新皮肤尚需用户实机观感确认。
