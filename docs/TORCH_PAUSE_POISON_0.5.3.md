# 火把、连续装备暂停与毒药修正（0.5.3开发版）

2026-10-11：用户已确认类型切换不再卡顿，随后报告火把无法装备、Pause+KeepOpen每次装备短暂恢复世界、毒药无法使用。此次保持版本号与先前字体/配置/绘制修改。

后续实测：用户确认上述三处修复全部通过。随后按用户要求将毒药从药水拆为独立分类，涂毒执行流程保留，见[POISON_CATEGORY_0.5.3.md](POISON_CATEGORY_0.5.3.md)。下方记录首次修复的分组与验证。

## 原因与改动

- 火把原来被列为可用，但装备分支未指定左手槽。现在仅可携带的TESObjectLIGH可用，两侧使用键都指定原版左手槽；重新选择已装备实例调用UnequipObject。执行前仍重新解析准确库存实例。
- 连续使用旧实现对所有保留动作都关闭暂停守卫，并等待至少150ms与两次玩家更新。现在普通Favorite非消耗品在Pause+KeepOpen时保持守卫，通过SKSE任务执行即时装备。仅当守卫实际打开、PausesGame为真且UI::numPausesGame为1时允许穿过暂停；不会修改计数或其他菜单标记。完成后立即提交轻目录刷新，无需玩家更新，也不从任务线程调用面光API。关闭、失败、读档、取消均清理新状态。
- 毒药原来显式标记为不支持且执行分支直接返回。现在归入药水分类，消费动作先闭盘，解除轮盘暂停后调用PlayerCharacter::UsePoisonFromInventory，由游戏处理武器检查、确认与消耗。左右使用键遵循原版目标武器选择，不自行指定手或写ExtraPoison。普通药水/食物保留原有EquipObject路径。

面光仍在其认可的玩家Update线程执行，保留原结算窗口；预设原本就关闭轮盘。Slow/Normal及消耗品动画路径不变。普通装备的第三方脚本或动画可能继续等到关闭暂停轮盘后推进，需游戏内测试。
