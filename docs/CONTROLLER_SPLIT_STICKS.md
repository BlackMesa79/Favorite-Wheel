# 手柄左杆移动 / 右杆选择

2026-10-10：用户确认左杆移动/右杆选择实机正常；本轮修正设置未应用就切换选杆的问题。当前仍为0.5.2开发测试版，最近正式版0.5.1。原实现验证记录保留在下文，新修正见SETTINGS_REFINEMENTS_0.5.2.md。

## 开启和操作

轮盘 → Start或F2 → 手柄 → 左摇杆控制移动 → 开启 → 应用；同时游戏行为页选择减速或正常速度。INI字段为[Controls] GamepadMoveWhileOpen=1；默认及旧配置缺键均为0。

只有成功应用后才切换实际选择杆。待应用开关、恢复默认值预览、取消和保存失败都保持原来的选杆；窗口顶部操作说明跟随已应用方案，选项值显示待保存值。

- 开启后右摇杆始终选择轮盘条目，包括暂停模式；松杆后保留选中条目。左杆不影响轮盘光标。
- 减速/正常速度时左杆原始轴值交给游戏，能够在开盘后起步、停止、转向和普通跑动。开关轮盘的队列/关闭阶段也保持轴值，避免人为停止；减速仍相对于已有速度，角色同样受游戏时间倍率影响。
- 暂停模式、设置和预设管理/命名窗口阻断左杆。设置/窗口仍使用已有暂停守卫，右杆在窗口中移动指针。
- 闭盘时若右杆仍偏离中心，暂不交给镜头；回中后恢复普通视角控制。失焦/读档/断连亦要求回中，避免旧选择偏移带动镜头。
- 关闭选项后恢复左杆选轮盘与“只保留开盘前移动方向到松杆”的旧方案；已经激活的右杆回中保护仍持续到回中，避免切选项瞬间镜头跳动。
- A/X确认/左手/管理、B关闭、Y切轮盘、十字键翻页、肩键/扳机两方案均保持；支持收藏与功能轮盘。

这版不新增冲刺按钮透传。普通左杆走跑和按键冲刺是两条不同路径；肩键/按钮继续用于轮盘，避免冲刺绑定同时切分类、使用物品或触发Horde声音槽能力。没有放行攻击、跳跃、潜行、左右杆按下等全部手柄输入；关闭后沿用原按钮松键保护。键鼠移动策略保持。

## 实现

ControllerSticks.h提供物理选杆、左杆Gameplay/HeldDirection/Block策略和右杆LookStickGate。输入批次预采集选择杆原始值，确认按键可取得同批次新选择；下游派发前才分流轴值，右杆选择不传给相机。实际选杆与输入分流读取AppliedGamepadMoveWhileOpen，在编辑期间使用事务开始时的saved值；只有保存验证成功才激活新值。进入/离开设置重置指针积分缓存，编辑开关时不清除当前杆向量，避免点开关立刻停住指针。

左杆分流读取小状态，不复制View中的物品详情；只有开启方案并处于捕获的实时模式时才额外复查玩家/焦点/阻塞菜单。输入仍在原派发钩子内，指针用原真实时间刷新；没有库存查询、新运行时地址、后台引擎调用或时间倍率改动。旧MovementStickGate与InputGate继续处理默认方案和按钮。

新增设置持久化字段、中英翻译与内置英文回退；既有语言部署只追加缺失键。手柄页五行，额外说明和操作提示按方案选择。保留已有主INI、主题和自定义翻译。

## 验证重点

自动覆盖模式/捕获/开闭/窗口/三种时间模式组合、左右选择源、起步/转向/窗口停步/恢复、相机回中交接/设置关闭/状态重置与旧模式回归。SettingsTests检查缺键关闭、保存/重载/独立进程读取、取消和布局/翻译。

实机：

- 开启后在减速轮盘静止起步、左杆连续转向、停步，再一边走跑一边右杆选药水/双手武器/法术；按钮不触发攻击或声音槽。
- 正常速度相同操作；暂停模式右杆选物品且左杆不能移动。收藏/预设/面光分类都能选择。
- 右杆保持偏移时B关闭/使用药水/应用预设，镜头应先保持，右杆回中后可转动；关闭过程中左杆继续原生移动。
- 进入设置/预设管理窗口停止移动，右杆可选择应用/取消，返回实时轮盘后左杆恢复当前方向；切选项、取消、默认值以及重启保持设置。
- 默认关闭仍左杆选轮盘；两种肩键方案、十字键、手柄入口修饰键与Horde隔离回归。
- 失焦、断连重连和读档没有旧光标漂移或右杆镜头跳动；需要回中一次是预期保护。
