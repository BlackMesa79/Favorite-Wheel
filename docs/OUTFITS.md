## 操作

Q 打开收藏；Shift + 收藏键打开功能轮盘；轮盘内 R 切换两种模式（F2 可改切换键）。两种轮盘分别记住页码，收藏分类保持独立。功能轮盘目前只有装备预设模块，A/D 暂无其他功能分类可切；W/S 或滚轮翻页。

功能轮盘前两格是“保存当前穿搭”“导入预设”，随后是已保存预设，最多 100 套，每套最多 64 件。左键预设执行，右键管理；缺失预设仍可右键修复、覆盖或删除。确认页 Enter 确认、Esc 返回。名称最多 128 UTF-8 字节，Ctrl+A 清空、Ctrl+V 粘贴 Unicode，Backspace 删除末尾字符；暂未对接中文输入法候选窗。

## 换装规则

- 管理当前玩家背包中 TESObjectARMO 类型、且不是盾牌的已穿戴实例，包括护甲、服装、首饰与护甲类饰品，不要求收藏。
- 不操作武器、盾牌、弹药、法术和其他非护甲物品，不从箱子或随从取物，不生成物品。
- 预设与当前受管理穿戴集合完全一致时，选择它只执行全卸。否则保留共有目标实例，主体优先穿戴缺少目标，确认目标全部穿戴后再清除旧衣物。只有额外衣物时只清理额外部分。
- 应用前解析整套预设，缺失或歧义则退出；还检查当前受保护任务装备与预设对已穿戴盾牌的槽位冲突。
- 解除轮盘自己的暂停后按预算分帧替换，单次更新最多两次原生调用、软预算3ms，每次重新获取基础物品与实例，不跨装备调用保留 ExtraDataList 指针。每步等待实际状态变化，单步最多750ms，总事务最多15秒，最后验证完整集合。换装期间不接受另一动作；保留轮盘模式完成后恢复暂停并允许继续操作。
- 不强制越过任务装备限制。其他模组的异步装备脚本可能阻止或改变穿戴，实际装备不是原子事务；中途状态变化会停止并通知，已完成的部分不会强行回滚。

## 保存与实例身份

预设随角色的 SKSE co-save 保存：创建、覆盖、命名、删除、导入后需正常保存游戏。加载旧存档会恢复旧的预设版本，加载没有本插件数据的存档时列表为空。读档恢复不会自动换装。

静态物品保存来源插件名和本地 FormID，因此一般加载顺序变化不会改变匹配；ESL 压缩导致本地 ID 改变仍需重建预设。动态物品和动态附魔通过 SKSE ResolveFormID 恢复，仅在本角色存档上下文中使用。

实例签名包括 ExtraUniqueID 与所属表单、实例附魔、强化值和玩家命名。不写入内存地址。没有UID时，完整签名相同的副本允许互换并优先选择已穿戴项，包括强化/附魔/同名副本；字段不同不回退。有UID但出现多个精确匹配仍拒绝。保存后再次强化、附魔、改名或新增UID可能使旧签名失效，请以当前穿搭覆盖更新。失效预设的详情指出首个问题配件及原因，日志记录匹配信息。

## 导入与导出

导出目录（游戏 Data 视角）：`SKSE/Plugins/FavoriteWheel/Outfits/Exports/`。
导入目录：`SKSE/Plugins/FavoriteWheel/Outfits/Imports/`。

右键预设 -> 导出，会生成带预设 ID 和时间标识的 UTF-8 `.fwo` 文件，不覆盖其他角色同编号的文件。将需要的 `.fwo` 放入 Imports，再在功能轮盘选择“导入预设”。MO2 下新建文件可能落入 Overwrite 或 MO2 配置的输出模组，需要从该实际位置管理。

导入读取 Imports 中所有 `.fwo`；先验证全部文件与库存后再追加，不覆盖当前预设；与已有名称及全部物品信息相同的预设不会重复追加。导入不会删除源文件。缺物、歧义、错误格式、重复实例或超限会取消本次导入。

导出是可转移的穿搭配方，会去除角色专属物品 UID；导入时根据本角色库存重新绑定实例。含动态表单或自制动态附魔的预设暂不支持导出，静态附魔装备可导出。目标角色需要拥有相应装备与一致的强化、附魔、命名；不会复制原角色物品。

文件有版本及长度限制，当前为 FWO 1 文本格式，非 Outfit Wheeler 格式，两者文件不能直接互导。

## 实机验证重点

保存便装和护甲两套，来回切换并再次点击卸下；确认武器、盾牌、弹药保留。测试强化/附魔同名实例、最后一件装备移出背包、额外首饰、受保护装备、保存后重启、两个角色切换、跨角色导入。原有收藏、药水和吃喝动画也需回归。
