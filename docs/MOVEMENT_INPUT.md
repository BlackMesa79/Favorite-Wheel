# 0.4.4 移动输入修复

用户报告：移动中开启轮盘强制停止人物；轮盘中按住W后关闭，有一段时间无法用W移动。随后用户选择“保留开盘前的移动方向，松键即停；轮盘内新按移动键只操作UI”。本轮按此规则实现，未将收藏操作与所有移动输入同时透传。

## 原因与修改

旧InputGate对所有已交给游戏的按钮在开盘时发送一次release，包含移动方向；所有轮盘中新按按钮吞到实际松键，关闭后仍按住的W也被持续吞掉。这是释放条件导致的阻塞，不是固定时长的冷却。主轮盘还设置kUsesMenuContext及kMenuMode，切入原生菜单模式可能进一步重置/重映射角色输入；0.4.4移除这两个设置，继续以原input dispatch门控管理独立叠加层，保留kDisablePauseMenu/kRequiresUpdate。暂停由独立固定标志的pause guard管理。

- 方向键按ControlMap的Gameplay物理绑定识别Forward/Back/Strafe Left/Strafe Right；支持重绑，不仅识别默认WASD。轮盘入口及被替换的原生收藏入口冲突时优先归轮盘，不作为方向键放行。
- 开盘前已转发给游戏的方向继续传递held及release；松开后再次按下只用于轮盘。新方向按键不改变人物方向。
- 当轮盘、暂停守卫都实际离栈后，仍按住的移动键从下一输入poll恢复，held事件仅一次改为新down，随后正常传递held/up。已在轮盘松开的新按键不产生孤立游戏release。保留的方向也补一次down，以恢复经过暂停窗口的输入。
- 左摇杆记录正常游戏的最近向量；捕获时锁定该向量，不随轮盘瞄准改变。回到20%死区内则归零，之后新推杆只瞄准；关闭立即交回当前真实向量。右摇杆持续拦截以避免选择时转动镜头。失焦、读档和无有效手柄时清空状态。
- 其他按钮继续旧门控：开盘前动作补一次释放，轮盘点击/攻击/扳机/入口吞到物理松键。Sprint等切换型动作不归入方向恢复，不人工恢复奔跑、潜行或攻击状态。

暂停模式及所有设置/预设窗口仍暂停世界；保留输入不意味着这些窗口中角色继续移动。减速/正常速度下角色可以沿开盘方向继续移动，也仍可能受伤死亡。

## 边界与review

输入分流先处理轮盘UI，再改原事件；不会将恢复down重新投送到本插件导航逻辑，不分配/注入额外ButtonEvent，也不写PlayerControls移动向量/强制打开引擎控制，不修改存档、INI或第三方控制状态。原字符/IME修饰键流程保留。InputGate和MovementStickGate由输入路径使用，不在Present中访问；现有加载状态清理方式沿用。

移除菜单上下文会改变第三方插件观察到的MenuMode，但轮盘仍发送自己的MenuOpenClose事件。原生UI消息及其他输入hook的完整行为须实机确认；单元测试不能证明原生菜单模式退出或输入法组合全部兼容。若下游插件继续拦截某事件，本插件的“已转发”记录不保证引擎最终收到了它。

## 验证

Release编译通过；WheelLogicTests、TimeTests、SettingsTests、NameEditorTests和RuntimeLayoutTests通过。WheelLogicTests新增跨开闭方向保持、轮盘新方向禁止移动、松开/重按、关闭后恢复held、仅一次down、无孤立up、鼠标攻击/入口保持吞键、失焦重置，以及左摇杆锁定/回中/重推/关闭恢复。RuntimeLayoutTests补充恢复down的实际按钮字段布局，验证五版本模拟布局、地址库格式1/2/5及实际0.4.4 DLL元数据；无新地址，未重复五份真实地址库扫描。本轮无新hook、绘制或翻译变化，不重复离屏渲染。自动测试只覆盖门控和字段，不代表完整原生移动/菜单/输入法流程已实机验证。

实机清单：

1. 减速/正常速度：先按住W移动再Q，人物保持方向；松W停止；轮盘新按A/D/W/S只导航；关闭时仍按方向立即移动。斜向W+D分别松开，应只停止被松开的分量。
2. 静止时Q→按住W→Q/Esc/点击物品关闭，W无需重新按就移动；轮盘内先松W再关闭，人物不得自行移动。暂停模式和F2/预设窗口进出同样检查关闭后的恢复。
3. 重绑移动键后重复；移动与轮盘入口绑定冲突时轮盘入口优先。轮盘内一直按左键/右键/扳机后关闭不能变成持续攻击；释放后新点击正常；数字快捷键仍正常。
4. 手柄先推动左摇杆移动再打开，保持原方向；推动瞄准不改变角色方向，回中停止，再推动只瞄准；关闭交回真实杆位。右摇杆不转镜头。上下D-pad入口差异保留。
5. 预设命名、Text Bridge中文输入、候选选择、设置捕获快捷键、面光与换装回归。Alt+Tab、读档、死亡、手柄断开或外部菜单取消后，不应残留自动移动或攻击。
