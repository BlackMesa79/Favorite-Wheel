## A. 装备预设部件自定义（P1）

### A-1. 旧预设兼容性
- [ ] 加载旧存档，对现有装备预设执行换装，确认行为与 0.9.0 完全一致。

### A-2. 部位模式（需先重新捕获预设）
> 旧存档里的预设 mask=0，**必须重新保存一次**才能让部位模式生效。

- [ ] 穿上一套装备，保存为新预设。
- [ ] 打开管理对话框，把"头部"改为"忽略"，再应用预设，确认头部已穿物品保持不动，其他部位正常切换。
- [ ] 把某部位改为"卸下"（该部位没有预设件），应用后确认该部位被清空。
- [ ] 把某部位改为"指定"，确认穿上对应件。

### A-3. 整套 / 叠加切换
- [ ] 管理对话框点击模式按钮，确认整套→叠加→整套循环切换，标签正确。
- [ ] 叠加模式下应用预设：只穿上预设件，不卸下不相交的已穿物品。
- [ ] 整套模式下应用预设：行为与旧版一致（卸下不属于预设的所有管理部位物品）。

### A-4. 宽松匹配
- [ ] 开启宽松匹配，把预设里某件物品换成同款但不同实例（例如强化程度不同），应用后确认能用替代件完成换装。
- [ ] 关闭宽松匹配，同样场景确认行为恢复严格匹配。

### A-5. 编辑部件子轮盘
- [ ] 点击"编辑部件"进入子轮盘，确认顶部显示"装备预设"（不是"面部光照"）。
- [ ] 子轮盘里看到预设件列表，每件显示名称和必需/可选标记。

### A-6. 存读档
- [ ] 设置部位模式和宽松匹配后保存游戏，读档，确认设置保留。
