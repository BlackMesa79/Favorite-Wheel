## 已实现

1. 手柄额外组合键让行：当前按住的按键超出入口、继承的原生修饰键以及轮盘配置的修饰键集合时，不打开轮盘；同样绕过替换入口的吞键分支。保留既有原生组合键及轮盘 Actions 组合键。这里不推迟单键响应，主键先按下、下一输入批次才按修饰键的情况不能预知。
2. 药物/食物保持打开：游戏行为设置新增独立开关，INI 为 General/KeepOpenConsumables，默认 false。与装备保持打开独立，毒药仍走关闭后的原生确认。沿用现有 retained action 流程，解除暂停、等待更新、重新获取库存；不新增重复消费事件。
3. 原生自由相机：统一 OpenBlockReason 检查 PlayerCamera::IsInFreeCameraMode，屏蔽新呼出。没有将其他相机状态一律禁用，不宣称覆盖所有第三方摄影模组。
4. 新增设置及帮助文案覆盖八种内置语言；部署追加新键，保留已有主配置及自定义值。
