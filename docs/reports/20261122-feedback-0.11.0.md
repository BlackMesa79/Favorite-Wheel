## 04 手柄 A + 方向键上被轮盘抢占

- [x] 0.11.0 已让行检测到的额外按键，呼出轮盘与替换原版入口的吞键分支都用此判断。但原生 XInput 包只用来补齐轮盘自身配置的修饰键和继承的 Favorites 修饰键。如果组合映射先把 A 的事件屏蔽，当前包即便仍有 A，这个 A 也可能进不了让行判断。A 被配置成轮盘修饰键，或上键先在另一输入包到达，也是应分别核对的情况。[让行与原生包逻辑](../../include/InputBindings.h#L132) · [运行时入口](../../src/Wheel.cpp#L904) · [历史修复](20261103-user-feedback-batch1.md)
- [x] 使用当前生产头文件在离线输入测试中复现。事件跟踪里保留 A 和上时，轮盘让行。同一组合的事件跟踪只剩上、XInput 包仍含 A 和上时，轮盘返回 `Favorites` 并捕获上。默认手柄修饰键且无原生 Favorites 修饰键时，日志特征应为 `heldMask=0001 engineMask=0401 openingMask=0001 mode=favorites`。这是合成事件的结果。[入口诊断字段](../../src/Wheel.cpp#L1356)
- [x] 离线验证一个候选判断。仅在当前原生输入包包含轮盘主键时，用此包识别额外按键。测试中它能识别被屏蔽的 A，允许单按上、显式配置为轮盘入口的 A + 上、继承的 LB + Y 及附加独立功能轮盘修饰键。样本不可用或不含主键时回退到现有事件判断。实装时需同时覆盖轮盘呼出和原版入口的吞键分支。[替换入口与轮盘呼出](../../src/Wheel.cpp#L915)
