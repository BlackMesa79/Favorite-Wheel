# SKSE Menu Framework 设置入口

## 接入范围
- 可选注册 FavoriteWheel → Settings，时机为 SKSE kPostPostLoad。
- 仅检测已加载模块；未安装或所需导出不齐时记录日志并跳过，原有轮盘设置继续可用。没有加载/执行磁盘上的框架 DLL 来探测。
- 四个折叠分组：外观（语言、主题、大小、位置、背景、提示、声音、动画）；游戏行为（物品来源、隐藏空分类、轮盘记忆、保持打开、时间）；键盘（入口键、切换键、修饰键、灵敏度、左右手）；手柄（入口与修饰键、分类按键、左摇杆移动）。
- 使用按键名称下拉选择；字体路径和启动 Enabled 开关不在页面中暴露。
- 复用现有语言资源，新增说明覆盖八语言。框架管理本页字体与布局，独立轮盘的 ImGui 上下文不用于绘制本页。

## 草稿及保存
- 页面编辑只修改本页草稿，不实时修改游戏配置。应用调用原有 INI 写入/校验流程；取消重新读取当前配置；恢复默认仅修改草稿。
- 草稿在关闭框架后仍保留，只有应用才生效。干净草稿在其他入口改变设置后自动刷新。
- 轮盘打开时不允许在框架页编辑；持久化入口在 settingsMutex 下检查轮盘编辑事务及基线配置，拒绝冲突写入。
- 保存失败恢复运行时配置，保留错误提示与日志，不显示保存成功。
- 不新增第二份配置，不修改框架自己的配置。

## 游戏验收建议
打开框架（本地 3.18 配置是 F1，以实际生效配置为准），进入 FavoriteWheel → Settings。
1. 改一个明显设置，例如轮盘大小或药物/食物保持打开，应用后回到轮盘核对；重启后确认保留。
2. 修改后取消，确认不影响原设置；恢复默认后取消也不应改变配置。
3. 核对中文显示和键盘/手柄设置下拉项。
4. 与乐器环境一起验收鼓、笛、鲁特琴实际演奏；这一项是先前 SGT 兼容待办，与本次设置页成功与否分别记录。
