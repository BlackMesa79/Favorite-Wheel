# 0.3.8 逐扇区折扇展开／收拢

收藏与功能轮盘共用220毫秒展开、220毫秒收起。使用已有 F2 动画开关，无新增依赖或配置键。打开从顶部开始顺时针逐扇区扫开；关闭逆序逐片收拢。各格等长运动窗口为总时间的52%，起始时刻等间隔分布在前48%内：10格每隔约11.7ms开始一格、每格运动114.4ms，最后一格在105.6ms开始并于220ms结束。关闭反向经过同一映射，最后一格先收，不添加逐格串行等待。单格使用smoothstep两端缓动，在窗口中点恰好完成一半位移，避免原cubic-out把大部分运动挤在起步阶段。

扇区从靠中心的小半径向外伸展，以一侧角边作为铰接起点舒展角宽；外环和刻度按各自扇区进度出现，不提前画出全圆。未开始的扇区不绘制。文字和原创图标沿扇区中线移动并稍后淡入，保持正向、正常比例及原生像素字号。稳定末帧恢复连续全圆外环及原布局。全局透明度在前28%进度内到达完整，避免遮住折扇运动；收拢最后阶段反向淡出。详情卡在展开42%后淡入并向外归位；标题/提示轻移8个设计像素。中心底板保留作为视觉锚点。设置/命名/确认面板只有淡入淡出。

## 操作时序

- Transition 只归属渲染线程，原始0..1进度驱动几何，较快的淡入曲线驱动全局透明度。开闭反向复用同一映射，不单独播放另一组关键帧。
- WheelSlot仍使用最终固定轮盘坐标，展开不阻挡点击、分类、分页或关闭，不调整灵敏度及圆形限位。
- 正常 Cancel(true) 立即发菜单关闭消息；等待实际菜单解除暂停后，原有动作队列提交。220ms收起只绘制lastView缓存，不延期动作，也不保留菜单输入。
- 失焦/加载/阻挡菜单的强制 Cancel() 不播放收起。快速重新打开保留当前进度、刷新快照与悬浮反馈。
- 实时时钟按帧推进，低帧率/卡顿的下一帧直接跨过已流逝进度，不按固定帧数播放。首次打开从0开始；中途反向所需剩余时长按当前进度计算。

## 渲染与验证

沿用游戏UI framebuffer/现有遮罩，没有场景拷贝、模糊、纹理或新渲染目标。字体准备仍按最终输出像素字号进行，与展开进度无关。DrawWheel可传入预览进度，默认1保持稳定显示。局部Reveal仅修改所属顶点颜色/位置，字体阴影随文字一起淡入，最后统一乘全局透明度。

SettingsTests覆盖220ms端点、禁用、强制取消、负时间、途中反向、各格等长窗口/顺序/单调有界以及位移中点；WheelLogicTests验证原动作策略和导航显示窗口。WheelPreview追加第11个参数（argv[11]，位置Y之后）为0..1进度，渲染同一姿态可代表展开或收起，默认1。预览检查全部顶点坐标有限，包括近零的窄角画面；弧线内缩量按进度缩放，避免起点超过终点。WARP输出只验证几何、字号和显示，不证明游戏内输入时延或帧率。游戏内检查清单见TESTING.md。

## 迭代记录

用户已认可0.3.5效果，但希望放慢至180–220ms。0.3.6仅调整200ms展开和180ms收起，随后用户要求0.3.7实装折扇时序，与时长一起测试。本版已将原12%轻错落改为58%等间隔启动窗口，并调整各格角度舒展和外环联动。游戏内体感和性能仍待用户反馈。

上述为0.3.7历史实现。用户反馈整体不错但运动仍太快；1.5.97玩家未发现明显问题。0.3.8按用户授权继续改善：两端缓动、延长单片运动到114ms，开闭统一220ms；顶部分类带和右侧分页随整体展开淡入，不改变开闭输入时序。新布局及动画实机手感仍待反馈。
