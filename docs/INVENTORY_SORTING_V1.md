# 轮盘排序：快捷键与分类排序

## 操作

移除工具小轮盘；F2（手柄 Back）直接打开设置。普通人形物品轮盘打开时，T 切换排序，Shift+T 进入／退出手动排序。Ctrl/Alt+T 不触发排序。若用户已将 T 配置为轮盘入口或切换轮盘按键，已有入口优先。排序键在物品轮盘内优先于同键循环快捷方式，不全局屏蔽其他模组。

鼠标保持径向限制。手动排序指向条目后左键或回车前移、右键后移，不受左右手交换设置影响；指针与页码跟随条目，首尾不循环，中心空白区不移动。手柄 LS 切换排序、RS 进入／退出编辑、A 前移、X 后移。切换分类／轮盘、进入设置或关闭时退出编辑。

## 排序模式

所有物品分类保留默认、名称升序、名称降序、已装备优先、自定义。

- 武器额外提供“武器类型”：使用游戏原生武器类型，区分单手／双手剑斧等；箭矢放在武器类型之后。
- 装备额外提供“轻甲／重甲／服装”和“穿戴部位”。部位顺序为头部、身体、手部、脚部、盾牌、戒指、项链、其他；多部位装备依据主显示部位归类，例如带兜帽长袍归身体。
- 法术额外提供“魔法学派”：使用游戏提供的所属学派，无学派法术放末尾。此模式不用于能力、龙吼分类。

同类型／部位按名称升序，完全同名保持原目录顺序。名称比较不是拼音排序。分类信息在游戏线程收集目录时读取。新增数值排序见 docs/NUMERIC_SORT_AND_HINT_MIGRATION.md；仅对应模式采集动态属性。

## 存档与限制

18 组分类／收藏或全背包状态独立保存，保存游戏才写入角色 .skse 配套存档。原有模式编号（特别是自定义 4）不变，新类型／部位追加为 5／6，数值排序追加为 7–10；可以加载此前存档。旧版本不支持包含新增模式的排序记录，降级使用前需注意此限制。分类元数据不属于持久身份，加载时从当前游戏重新收集。

自定义顺序不会改变背包数据或原生数字快捷键。功能轮盘、战斗循环执行顺序和吸血鬼领主仍不参与本功能。拖拽排序第一版现已实现，见 docs/DRAG_SORT_V1.md。
