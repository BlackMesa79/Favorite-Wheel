# 0.4.8 魔法顶层分类

用户选择将原魔法页拆为法术、龙吼、能力三个顶层分类，不引入子分类。分类顺序为武器、装备、药水、食物、法术、龙吼、能力、其他；A/D或LB/RB仍循环全部类型，顶部最多显示5个相邻标题、选中居中。W/S/滚轮/十字键上下仍翻当前类型物品页。空类型保持可导航，与原规则一致。

## 数据与使用规则

MagicCategory按游戏记录分类：TESShout优先为Shouts；SpellItem的kSpell为Spells，kPower/kLesserPower/kVoicePower为Powers。kAbility为游戏内部被动效果，不是主动能力，和疾病、附魔、药剂及其他内部类型一起不发布为可执行条目。分类策略模板在运行时使用CommonLib真实SpellType，RuntimeLayoutTests以真实枚举进行编译期验证，WheelLogicTests验证独立政策与八类导航。

三个分类继续从MagicFavorites读取，并检查玩家实际拥有；全部背包模式也只显示已收藏的法术/龙吼/主动能力，不扩展到全部已学魔法。ResolveItem同时校验允许的主动类型，防止旧快照执行被动效果。卷轴作为实体背包物品保持Other分类，不混入已学法术。没有改动收藏/装备/原生快捷槽数据。

法术仍按原规则装备左右手/双手，龙吼通过EquipShout、能力通过自身装备槽的EquipSpell。轮盘只选择装备，不自动施放；能力/龙吼正常由游戏的声音槽按键发动。左/右手、原生1–8分配、效果详情、已装备标记共用原执行和显示逻辑。

Category::Magic改为Spells，插入Shouts/Powers，类别总数8。此枚举只用于进程目录/视图，不写INI或co-save，预设存档与配置不迁移；原会话记忆自然记录拆分后的类型。InventoryPages边界数组随categoryCount扩展，sort按类别分组，当前页最多10项。图标自动回退与标题数组有编译期长度检查，三个魔法类型本轮共用原魔法图标，没有重绘图标库。

## 本地化与性能

新增翻译键spells/shouts/powers：英文SPELLS/SHOUTS/POWERS，中文法术/龙吼/能力；旧magic保留供旧语言文件参考但当前分类不再读取。缺译文回退英语，自动部署只追加缺失键、保留已有自定义值。分类比较在原遍历中执行，无额外库存扫描或每帧属性读取；八类目录额外两个边界，性能不随分页总数增加。

## 验证与待测

WheelLogicTests包含八类1–8数量的五标题窗口、无重复/居中、三类邻接导航、主动/被动分离及原0.4.7手柄边沿回归；InventoryTests八类各10003项，总80024项，检查所有类别末页边界/精确选择、空目录和一万次最多10项快照。通过，合成耗时不能代替游戏内帧时间。Release自动部署成功，SettingsTests新中文标题及旧partial语言的英语回退通过，RuntimeLayoutTests真实SpellType编译期分类、五模拟布局/地址库格式1/2/5夹具、实际DLL0.4.8元数据通过。

实际Draw的WARP离屏检查720p英文法术、1440p英文手柄龙吼、1440p中文能力三个场景，标题最多5项、当前居中、三类图标回退均正常；字体预热/复用、遮罩与稳定扇区不透底验证通过。使用合成数据，非游戏截图。安装与构建DLL SHA256相同；主INI/四主题/meta文件精确哈希保留，语言旧key/value逐项保留，仅补入三个新分类键。

实测普通法术、双手法术、龙吼、大能力/小能力，分别收藏后开盘分类正确、装备与声音槽已装备标记、数字快捷槽、详情、W/S与十字键多页、A/D与LB/RB切类型并保持光标、关闭重开记住新类型。切全部背包仍只显示收藏魔法，卷轴在其他，被动能力不出现。旧配置/存档/面光/装备预设及药水动画保留回归。本轮未收到新实机结果，0.4.7手柄与此前装备匹配/标记仍待反馈。
