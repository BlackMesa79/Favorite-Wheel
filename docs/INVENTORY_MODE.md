# 全部背包模式（0.4.1）

收藏逻辑仍为默认。Q → F2 → 控制 → 物品来源 → 全部背包 → 应用，可显示玩家携带的所有物品。INI 为 `[General] AllInventory=1`；默认值/旧 INI 缺键为 0。取消设置不改变目录，应用才重新采集；不自动收藏任何物品。

## 范围与行为

- 分类沿用武器、装备、药水、食物、魔法、其他。全模式分类内已装备优先、收藏其次，再按名称及实例排序。
- 魔法仍只列出收藏法术/龙吼，不扩展为所有已学魔法。
- 无 ExtraDataList 的普通堆叠可以显示和使用；附魔、强化、改名等特殊实例保留独立身份，执行前重新验证，不向同 FormID 的其他特殊实例回退。
- 同 FormID 的总数量按实际库存分配，避免普通剩余数量与特殊实例重复。普通剩余量可并入兼容普通实例；全模式额外排除所有权、充能、毒药、灵魂差异。
- 装备/消耗品执行路径沿用原版 ActorEquipManager；药水/食物仍只提交一次装备调用，以保留动画模组触发。
- 书籍、原料、杂物和毒药可显示，但本版不新增阅读、吃原料或涂毒动作。数字 1–8 只能绑定已经收藏的物品/法术；非收藏项提示先在库存中收藏。
- 功能轮盘、原暂停行为及快捷键不变。目录只覆盖玩家库存，不读取随从、箱子或附近物品。

## 性能策略

`CollectInventory` 在游戏线程同步借用原生 inventory changes 与基础容器数据；不调用全量 GetInventory 来克隆实例节点。只读取名称、数量、分类/图标、实例身份、穿戴/收藏与快捷槽；不在开盘时计算所有物品属性和效果。

`InventoryPages` 保存本次开盘的轻量目录与分类范围。运行时 View 只发布当前页至多 10 项，输入和渲染 Snapshot 不复制整个分类。分类切换/翻页的复制量不随库存规模增长，右侧页码窗口也有数量上限。快捷槽分配仍需要扫描并清理冲突，属于显式操作，不发生在每帧。

悬停稳定约 80 ms 后，在 SKSE 任务读取单项属性；最多一个详情任务排队，结果缓存到本次开盘目录。查找只解析目标 Form 的新鲜原生 entry，不克隆全库存。epoch、openSerial、directoryRevision、菜单/焦点/玩家和 key 校验可丢弃旧任务。任务返回的详情不包含引擎指针；借用的 extra 指针仅在游戏线程的新鲜验证后使用。

直接打开功能轮盘跳过库存目录；首次切到物品才采集。每次重新打开重新采集，防止消耗、交换、改名等变化造成跨开盘陈旧目录。字体只准备当前页及界面所需文本，不预热完整库存的名字/效果。

开盘仍有 O(N) 枚举和 O(N log N) 排序，发生在创建暂停菜单之前。新字形可能导致字体 atlas 重建/上传；本版并未消除所有初次打开卡顿。不能将分页合成测试当作真实库存采集或游戏 FPS 基准，也不能把安全性尚未核实的引擎读取移到工作线程。

## 验证与诊断

本地 InventoryTests 验证数量分配、收藏默认门槛、60018 项合成目录的最后页/边界/精确选中与有界页快照。SettingsTests 验证默认、旧配置、保存/重读和取消/恢复默认。实际 DrawWheel 离屏预览覆盖 2560×1440 万项分类、720p 控制页和功能轮盘，并人工检查；这些不是游戏截图或真实库存测试。

日志 `Inventory directory: scope=all items=... details=false total_ms=...` 是目录采集/排序时间。`Native-size font atlas: ... visible_items=... build_upload_ms=...` 是字体准备和 GPU 上传时间；超过 8 ms 的单项详情读取记录 `Inventory detail`。真实大背包测试步骤见 TESTING.md。0.4.1 新模式尚未游戏内验证；运行时支持沿用 0.4.0，不增加白名单。
