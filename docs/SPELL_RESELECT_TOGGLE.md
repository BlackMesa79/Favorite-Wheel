# 法术再次选择解除装备

普通人形下，法术分类采用与武器一致的目标手切换：目标手没有此法术则装备；已有则清空目标手。同一单手法术装备于左右两手时，只解除点击对应的一手，替换旧的“保留目标手、清空另一手”行为。另一手装备其他法术或武器时不受影响。鼠标左右手交换和手柄继续通过现有输入映射决定目标手。

必须双手施放的普通法术，任意点击均清空该法术实际占据的左右槽位；尚未装备则仍按原生槽位装备。只对普通 Spell 类型开启切换，能力、龙吼以及吸血鬼领主专用分支保持原样。手动排序仍优先处理排序，不执行装备。

继续使用既有 ClearFavoriteSpell → Actor.UnequipSpell 注册方法，不直接修改 selectedSpells，不修改暂停策略。调用成功代表已提交给游戏，不代表异步卸下已经完成；原有完成回调记录实际槽位状态。

验证：HandEquipTests 覆盖普通／非普通、单手／双手、左右目标手及各装备状态组合，重复点击、另一手追加装备以及失败不回退装备。WheelLogicTests 通过。构建成功并自动部署，部署 DLL 哈希与产物一致：F9FBB76DB5528DEBB25FFEBB5D390405B7F2D09C3EE8312C5CCCAACD5902CEC8。用户主 INI 哈希保持不变。未接管键鼠或进行游戏内验证。

游戏内复测重点：单手连续装备／卸下；双持同法术时只卸目标手；左右不同法术时保留另一手；双手施法法术整体卸下；暂停、减速和正常时间模式下实际完成与轮盘标记刷新。若游戏中未卸下，检查 Spell hand request 与 Spell hand clear completed 日志，而不能仅凭 submitted=true 判断完成。
