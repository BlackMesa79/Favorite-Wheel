# 0.3.17 输入与快捷键

收藏轮盘、功能轮盘的键盘入口独立设置；设置页分外观/控制两页。旧INI缺失新字段时维持Q/Shift+Q/R。

## INI [Controls]

| 字段 | 默认 | 规则 |
| --- | --- | --- |
| Hotkey | -1 | 跟随游戏键盘 Favorites；否则 DirectInput 扫描码 |
| HotkeyModifier | 0 | Shift=1、Ctrl=2、Alt=4，可相加；0为无 |
| ActionHotkey | -1 | 跟随有效 Hotkey（含自定义覆盖） |
| ActionModifier | 1 | 同上，独立组合 |
| SwitchWheelKey | 19 | 打开后切换轮盘；R=19，F2保留给设置 |
| GamepadHotkey | -1 | 跟随游戏手柄 Favorites，否则SKSE按键码 |
| GamepadModifier | -1 | 无修饰键，否则手柄按键码 |
| GamepadActionModifier | 274 | LB；与手柄收藏轮盘共享主键 |

手柄码：266上、267下、268左、269右、270Start、271Back、272LS、273RS、274LB、275RB、276A、277B、278X、279Y、280LT、281RT。PlayStation由SKSE转换到相同位置；提示采用Xbox名称。修饰键不能与主键相同。

键盘组合精确匹配，额外修饰键不触发。左右Shift/Ctrl/Alt等价。两个入口相同则功能轮盘优先，控制页提示冲突。主键捕获时按住修饰键再按主键，或单独循环选择组合。手柄B/Esc取消捕获，因此B不可从捕获页设为主键。手动INI修改需重启游戏。

## 手柄操作

游戏收藏键（通常十字键上）打开收藏；LB+收藏打开功能。左摇杆径向选择，松开保留当前选择，A使用/右手、X左手/预设管理、B关闭/子列表返回、Y切换轮盘、Start设置；LB/RB或十字键左右切换分类、十字键上下切页。打开后入口键用于导航，不作为关闭键。

设置/对话框左摇杆控制自由光标，A点击、X重置设置、B取消，设置LB/RB换标签页。轮盘内直接按方向选择，不依赖帧率；设置光标移动按实际渲染时间积分，受灵敏度控制且限定视口。摇杆死区20%，中心回弹不清除轮盘选中项。名称输入仍需键盘/输入法，本版无虚拟键盘。

## 数字快捷栏反馈与0.3.17补齐

0.3.16之前的入口匹配接受所有userEvent=Favorites，不管实际按键是否等于游戏收藏键。现仅匹配实际物理绑定；无映射/0xFF不匹配，避免快捷键/控制映射集成传同名事件时误当轮盘入口。除轮盘打开/关闭等待阶段、按下入口后直到松开的防穿透状态外，其他事件原样转发。0.3.16没有改写原版快捷槽；0.3.17按用户选择增加下面的原版槽位分配，取消绑定仍保留ExtraHotkey数据。

按下主键盘0–9或Numpad0–3时，日志以`Numeric shortcut input`记录原始scan/event与filter=pass/release/suppress，能区分轮盘是否拦截；pass只证明事件转发，不证明其他插件/引擎成功处理。

自动回归覆盖Numpad0/1/2/3和主键盘数字：在默认绑定下不会开轮盘，关闭时按下/持续/松开均透传；仅将游戏收藏键本身替换。用户后续提供英文原文明确为收藏中的1–0数字快捷栏，没有明确说数字小键盘。用户选择补齐原版快捷槽分配方式；0.3.16的事件匹配修改只是防误拦，不能把它当成该反馈的完整修复。

## 0.3.17 原版快捷槽操作

收藏轮盘悬停物品后按无修饰键1–8（DirectInput扫描码2–9）分配原版槽0–7；同数字取消，换数字迁移，已有占用释放。语义Hotkey1–Hotkey8优先识别游戏重绑，其他Hotkey9/10事件不新建槽。与入口/F2/切换键冲突时轮盘控制优先。空中心/空扇区不绑定；功能、设置和名称输入不绑定。

库存对象读取并修改已收藏实例的ExtraHotkey.hotkey，取消值为kUnbound而不删除ExtraHotkey（该数据的存在同时标记收藏）。先CollectFavorites(false)重新核对Form/extra/unique/附魔/强化，随后更新指定实例以及冲突槽，标记玩家库存change flag。法术/龙吼读写MagicFavorites.hotkeys，数组不足八槽先扩容；取消/迁移只操作前八槽，保留扩展槽。

变更在SKSE游戏任务线程执行；generation/openSerial校验确保关闭/重新开启/失焦/读档不执行旧请求。成功后只刷新轮盘数字快照，保留类别、鼠标、物品属性。没有新增存档记录或游戏外数字键消费逻辑。关闭轮盘后数字键使用交给原版，9/0扩展键仍透传。原生存档持久化须实机保存/退出/读档验证。

新增可翻译quickSlotHint，扇区外沿显示1–8数字徽标，与装备状态标记错开。底部键鼠收藏页第三行提示分配，不改变功能页/手柄提示。
