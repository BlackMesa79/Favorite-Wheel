# 独立毒药分类（0.5.3开发版）

2026-10-11：用户实测确认火把装备、暂停下连续装备和毒药使用三处修复均通过，要求将毒药与普通药水分开。

- 新增一级“毒药”分类，排列在药水与食物之间。使用原版IsPoison标记识别，不按名称猜测；食物和普通药水继续分到原分类。
- 独立的棱角瓶形与交叉标签图标，区别于圆形药水瓶；自动图标回退映射同步扩展。补齐八种语言的poisons标签及内置英语回退，字形仍使用已有全目录预热。
- 分页、分类导航、隐藏空分类共用现有目录边界与可见性逻辑；最后一种毒药耗尽后，隐藏空分类会跳到下一个有物品的分类。
- 分类拆分仍将毒药视为消耗品，无论KeepOpen或时间模式都先闭盘，再走已通过实测的原版涂毒入口；火把和暂停装备修复保留。

新增分类未写入存档或INI，不需迁移现有配置。部署只追加缺失的语言标签，已有自定义翻译值保留。
