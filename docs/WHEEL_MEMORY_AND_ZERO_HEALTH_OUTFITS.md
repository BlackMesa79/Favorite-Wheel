# 轮盘记忆与零值装备换装保存修复

## 轮盘记忆

F2 → 游戏行为 → 记住上次轮盘，默认关闭。开关保存为 General/RememberLastWheel；缺失配置沿用关闭，不在部署或启动时重写用户主配置。

开启时，普通收藏入口（默认 Q，包括手柄对应入口）重新打开本次会话最后使用的物品或功能轮盘。轮盘内切换也更新记忆；专用功能入口始终直接打开功能轮盘。限制形态强制使用允许的物品轮盘且不覆盖人形记忆。读档、新游戏或会话结束清除记忆；开关本身保留。原有分类／页面记忆逻辑不变。

## 换装保存

用户日志中 Madesi's Silver Ring (Skyrim.esm:76F12, UID 0) 和 Cultist Robes (DealingwithDaedra.esp:5117F0, UID 80) 的 ExtraHealth 为 0。捕获直接读取该值；此前 PieceDataProblem 要求 >0，导致整份编码记录解码校验失败，从未保存。旧版的“最多 100 套”通知误报了这种数据失败，因此重载为 0 套与捕获被拒绝一致。日志没有证明 ARMA 模型数量是原因，也没有证明生成零值的具体来源。

现在允许有限非负值，原样保存 0 并按原值匹配，不强制改成 1、不修改实际装备。负数、NaN、无穷大继续拒绝，其余名字、数量、身份和唯一性约束不变。FWO 格式版本不变；旧版仍会拒绝含零值的预设，回退版本不应期待读取这些新增预设。之前没有保存成功的预设需重新创建。
