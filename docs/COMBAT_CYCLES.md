# 战斗循环（0.8.0）

2026-10-24：用户已在游戏中测试循环战斗预设，反馈没有发现问题；未提供逐项测试清单，不扩大为全部边界或运行时均已验证。此前整体代码审查和优化待办保存在 `CODE_REVIEW_2026-10-24.md`，暂不在本次 UI 调整中实施。

本次调整：悬浮战斗预设或循环成员时，轮盘中间显示所属循环组编号，例如「循环组 / 1 / 3」（标题和编号分两行）。属于多个组时列出全部编号；未加入任何组则不显示。扇区不增加标记。编号采用固定组 ID，不受改名或改键影响。

循环组把已有的战斗预设按顺序串起来。游戏中重复按同一组合键，会依次应用下一套可用预设，到末尾后回到第一套。无需其他模组，也不需要单独的配置菜单。

## 快速使用

1. 装备好第一套武器、法术或盾牌，打开轮盘，按 **Shift+1** 加入循环组 1。
2. 换好另一套，再打开轮盘按 **Shift+1** 加入同一组。也可以在战斗预设页面悬浮已有预设，再按该组合键加入它。
3. 关闭轮盘，在游戏中重复按 **Shift+1**，依次切换组中的预设。首次从第一项开始；同一套预设不会重复加入同一组。
4. **保存游戏**。循环组、成员顺序、自定义按键及当前位置保存在角色的 SKSE 配套存档中，不写入全局 INI。

默认提供八个组，使用 **Shift+1–8**。轮盘外，空组不会拦截按键。轮盘内，组合键用于加入预设，给予 HUD 提示，无需确认窗口；若未悬浮战斗预设或循环成员，则捕获玩家当时实际装备的双手。

## 管理与改键

打开功能轮盘，切换到「战斗循环」。左键组图标应用下一套，右键管理该组。可重命名、绑定快捷键、清空组，或进入「编辑成员」。成员列表中左键应用指定成员，右键调整顺序或移除。

在「绑定快捷键」状态按主键，可搭配 **Shift、Ctrl、Alt** 及其组合。左右修饰键等效；Esc 取消录入，Backspace 或 Delete 停用该组的键盘绑定。鼠标仍可通过轮盘应用未绑定的组。重复组合键及轮盘入口冲突会被拒绝；裸 **1–8** 保留给已有物品／战斗预设快捷槽，F2、Esc、Tab、Enter 等菜单键不能绑定。其他模组的组合键冲突仍需自行避开。

组的成员上限为 64；战斗预设仍共享原有的 100 套上限。删除战斗预设会同步移除所有组对它的引用；清空组或移除成员不会删除底层预设。快速捕获会复用双手内容相同的已有预设，否则自动创建有默认名称的新战斗预设，可在战斗预设页重命名。

## 应用规则

- 本阶段每项是**完整双手预设**，包含明确的空手状态；未实现「只改一只手，另一手保持现状」。
- 沿用战斗预设的武器实例、法术、盾牌、火把、双手装备和装备确认逻辑；法术只装备，不施放。
- 缺失或已不可用的预设会在开始装备前跳过。全部不可用时提示，保持原有装备。
- 只有引擎确认应用成功后才推进循环位置。应用中断或失败不推进；部分装备失败仍可能需要手动恢复装备，与单个战斗预设一致。
- 装备任务进行中不会叠加多个请求；等待上一套完成后再按。悬浮复制、绑定、排序与清空不会在装备任务中修改组。
- 旧存档没有循环数据时初始化为空组。循环使用独立、带版本的序列化记录，读取完成后清理已不存在的预设引用，不修改旧战斗预设格式。

## 本轮验证与游戏测试

新增 `CombatCycleTests` 覆盖顺序、回绕、失败不推进、去重、限制、组合键冲突、序列化及输入按下／释放生命周期；原有测试与 WARP 离屏界面检查一并运行。真实游戏装备和存档重载仍需要手动验证：

1. 三套不同武器／法术循环，确认回绕、双手及空手语义。
2. 暂停、慢速及正常时间三种轮盘设置下快速捕获；悬浮预设直接加入，确认操作结束后仍能使用轮盘。
3. 改为 Ctrl+F 或 Alt+数字；确认原有裸 1–8 快捷槽仍工作，松开修饰键再松主键不会误触。
4. 成员排序、移除、清空、关闭绑定、重命名；保存、退出并重载，确认数据和循环位置保留。
5. 使一个预设不可用，确认跳过；全部不可用、战斗预设删除及装备中连续按键时，确认提示与当前位置正确。
