# Favorite Wheel - Radial Actions 0.3.14 发布材料

- 正式安装包：`dist/FavoriteWheel-0.3.14.zip`，仅运行文件及根目录 `readme.txt`，不附带开发文档、封面、独立许可目录或校验文件。readme 合并 GPL-3.0 全文与所有第三方许可及例外文本。
- 对应源码：`dist/FavoriteWheel-0.3.14-source.zip`，与安装包分开分发，包含固定依赖源码与构建说明。

- `Nexus-summary.txt`：英文短简介，可粘贴到 Nexus 的 Summary。
- `Nexus-description-en.bbcode.txt`：英文详情页，使用 BBCode 编辑模式粘贴；以 Face Lighting SKSE 的详情页结构为模板，描述当前已实现功能。
- `Nexus-preview.html`：本地详情页排版预览。
- `FavoriteWheel-cover.svg`：可编辑纯矢量封面，无中文。
- `FavoriteWheel-cover.png`：2560×1440 封面。
- `FavoriteWheel-cover-1280.png`：1280×720 预览。

公开标题使用 **Favorite Wheel - Radial Actions**；主标题仍是 FAVORITE WHEEL，标题扩展为 RADIAL ACTIONS，封面副标题为 **Your favorites and actions, at your fingertips.** 不改变 DLL、配置文件、存档标识或安装路径。

兼容性按照用户反馈标记：1.5.97 与 1.6.1170 已经过游戏内测试；1.7.x 支持但尚未游戏内测试。当前 DLL 精确支持的 1.7 版本为 1.7.99 与 1.7.104，未宣传任意未来 1.7.x 版本。1.5.97 的反馈来自之前的测试版，不代表当前每项功能均在该版本逐项复测；用户已确认旧 0.3.13 游戏内测试没有发现问题；新增自动语言选择仍待实机回归。

面光和 Text Bridge 均为可选联动；未填写未经确认的 Nexus 模组链接。源码地址由用户确认为 https://github.com/BlackMesa79/Favorite-Wheel ，已加入详情页。面光通过兼容 API V1 检测，不按模组发布版本号强绑定。详情页说明不把设置开关等同于实际照亮，也不宣传尚未实现的扩展模块。

默认配置改为 Language=auto，根据 Windows 显示语言匹配翻译，不可用时回退英文。旧手动选择和旧 Chinese 配置继续保留；用户可在 F2 选择跟随系统。翻译指南为 docs/LOCALIZATION.md，详情页已附 GitHub 指南链接。

本轮更新至 0.3.14，新增系统语言自动匹配、跟随系统设置选项及解析后语言的统一字体选择。详情页保留 GitHub 源码地址，移除 I4/SWF 图标调查记录和无具体使用价值的渲染兼容性调查段落。未上传 Nexus。
