New in v2: fix selection of the UI render target
The previous test assumed the target bound on entry to a custom menu callback
was the UI layer. The paused path could instead inherit a scene/HDR target.

actual resource/dimensions after any renderer redirection. The original render
targets and depth binding are restored, including on exceptions.
